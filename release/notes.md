# Cybex OS 1.0.15

- Dictation gains a third speech model, **Fast & accurate** (NVIDIA Parakeet TDT v3). It covers 25 European languages, recognises the language by itself and shows live words like the other models. The first-use offer recommends it when your languages are among them.
- **Words**: add names and terms, and corrections such as "cyber os" → "Cybex OS". Corrections apply to the live words and to the typed text, with every model. If you make the same fix twice in the history, it is suggested as a correction.
- **Tidy up**: Off, Basic (the default: hesitations removed, capitals and a full stop) or Polish. Polish has your own Claude Code or Codex rewrite the text once, with no tools and no saved session, and falls back to Basic if that fails. Terminals and code editors get the words exactly as heard. Clicking the pill types the original text, and Copy original is available afterwards.
- **History**: every dictation is kept for 30 days by default. Words that could not be typed are kept until they are typed. Recordings can be kept too (optional). Open the history with Super+Ctrl+Shift+X, a middle click on the indicator, the pill or Settings. From there you can type, copy, correct, play, re-transcribe or delete entries.
- Settings → Assistant now has Wiz and Dictation tabs. The Indicators page links to the dictation settings.
- Stay awake now really turns off. A startup with Stay awake set to Off, an expired timed request or a change made in the settings file could leave the screen kept awake. Switching it off and quickly on again now keeps it on.

Validation covers source regressions (`tests/run`, QML lint), the new Stay awake regression cases in a real Quickshell engine, Voxtype's own test suite with the Cybex OS patch, the prebuilt-package check, the dictation NixOS VM test (history panel, a correction, the Polish fallback, a kept recording, Accurate and Parakeet in English and Dutch), Nix evaluation and the actual local staged-updater lifecycle in an isolated NixOS VM. Polish was tried by hand against real Claude Code and Codex accounts.

This is a source release with no new ISO attached. The existing 1.0.10 testing ISO retains its original source and does not contain these changes. Fresh ISO installation, applying the release through a published channel, a live session, real voice input and physical hardware qualification have not been run for this release revision.
