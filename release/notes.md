# Cybex OS 1.0.0

The first release of Cybex OS: a NixOS desktop with a graphical installer,
machine-owned configuration, independent Nixpkgs and Cybex OS inputs,
authenticated release channels, persistent personal extensions and staged
generation deployment. See `docs/installation.md` to write the installation
medium and install, and `docs/validation.md` for qualification status.
Installation is fresh; earlier Fedora-based Cybex OS installations are not
migrated.
